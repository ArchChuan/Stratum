# 产品入门指南

欢迎使用本平台。本文面向首次使用产品的新用户，介绍从账号注册到完成首次项目配置的完整流程，帮助你在最短时间内上手。

## 注册与登录

新用户访问平台首页，点击右上角「注册」按钮，填写邮箱并设置密码即可创建账号。创建完成后系统会向注册邮箱发送验证邮件，点击邮件中的链接完成邮箱验证。此后每次登录都使用邮箱加密码，也可以开启短信或邮箱验证码二次确认。

如果忘记密码，可以在登录页点击「忘记密码」，通过邮箱重置密码。账号一旦创建，邮箱即成为登录凭证，无法自行变更。

## 创建组织与项目

登录进入工作台后，第一步是创建组织。输入组织名称、选择行业分类，即可完成创建。组织是权限和计费的基本边界单位，一个账号可以同时加入多个组织。

创建组织后，在「项目」页面点击新建项目，填写项目名称并选择数据接入方式。平台支持直接上传文件、连接数据源以及通过 SDK 接入三种方式。首次创建项目时，系统会引导你完成环境配置，包括选择区域、设置默认存储位置等。

## 邀请成员与申请权限

在「成员管理」页面输入成员的邮箱并发送邀请，成员接受邀请后自动加入组织，默认获得「普通成员」角色，仅拥有查看与协作权限。普通成员如果希望获得更高权限，可以在「权限申请」中提交申请，说明用途后由组织管理员审批。审批通过后，系统会按角色模板自动授予相应权限，并在成员列表中记录。

## SDK 接入

开发者可以通过 SDK 快速接入平台。在「开发者设置」中创建应用后，系统会生成专属 token。SDK 支持环境切换，可以在开发环境、测试环境与生产环境之间灵活切换，token 与目标环境绑定。接入完成后即可调用平台能力进行数据同步与检索。

关于计费与账单的说明请参考计费与账单文档；关于数据安全、加密与合规的说明请参考安全策略文档。
